## 🌱 GitHub Forking — Concept and Usage

### 🔹 What is Forking?
Forking means creating a **copy of someone else’s GitHub repository** under your own GitHub account.

It allows you to work on or study a project independently without affecting the original repository.

---

### 🔹 Why Forking is Important
- To study other developers’ projects
- To experiment safely with code
- To contribute to open-source projects
- To keep reference implementations in your own GitHub profile

---

### 🔹 Forking in Real-World Projects
- Commonly used in team and open-source environments
- Helps in learning best practices
- Allows comparison between your implementation and others

---

## 🔁 Forking vs Cloning (Conceptual Understanding)

- **Forking** creates a copy on GitHub
- **Cloning** downloads the repository to local system
- Forking is usually done first, followed by cloning
